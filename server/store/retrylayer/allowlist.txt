# The retry allowlist. layergen turns each line into a retrying override in
# forwarding_gen.go; every other store method is forwarded exactly once. A
# retried write that is not idempotent commits twice, so add a line only for
# a read or for a write whose replay is proven safe.
#
# Each line is "Contract.Method mode":
#   always   retry every transient failure.
#   command  retry only when the *store.CommandIdempotency argument is
#            non-nil; its durable outcome makes a replay safe. A call
#            without one runs once.
#
# Generation fails on a line that names no contract method.
